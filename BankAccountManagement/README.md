# Bank Account Management System

## Overview
A simple Java console application that simulates
basic bank account operations.

## Features
- Create a bank account
- Display account details
- Check account balance
- Deposit money
- Withdraw money
- Validate transactions
- Handle exceptions

## Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Getters
- Methods
- Conditional Statements
- Exception Handling
- try-catch
- throw

## Technologies
- Java
- VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Navigate to the BankAccountManagement folder.
4. Compile the Java files:

   javac Day21/*.java

5. Run the program:

   java Day21.Main
